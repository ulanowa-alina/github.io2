# Изображения главного экрана

Загружайте файлы под указанными именами. Лучше использовать PNG или WebP; для
персонажа, логотипа и иконок нужен прозрачный фон.

## Обязательные файлы

- `backgrounds/hero-city.webp` — чистый городской фон верхней части, без героя,
  текста, карточек и маршрута. Рекомендуемый размер: 1920×760 px или больше.
- `backgrounds/mission-strip.webp` — чистый синий фон нижнего блока, без линии,
  кружков, иконок и подписей. Рекомендуемый размер: 1920×360 px или больше.
- `characters/hero.webp` — герой отдельно, на прозрачном фоне. Рекомендуемая
  высота: 700–900 px.
- `branding/logo.webp` — логотип «Операция: Посылка для Макара» на прозрачном
  фоне. Рекомендуемая ширина: 420–600 px.

## Иконки миссий

Все иконки — квадратные PNG/WebP с прозрачным фоном, желательно 256×256 px:

- `missions/mission-01.webp` — карта с меткой;
- `missions/mission-02.webp` — лупа с вопросом;
- `missions/mission-03.webp` — лист / часть кода;
- `missions/mission-04.webp` — город;
- `missions/mission-05.webp` — паутина;
- `missions/mission-06.webp` — небольшой подарок;
- `missions/mission-07.webp` — главная награда / большой подарок.

## Дополнительно, если есть готовые изображения

- `ui/message-portrait.webp` — небольшая оригинальная маска паука-героя для
  карточки сообщения;
- `ui/code-piece-empty.svg` — серая часть кода;
- `ui/code-piece-found.svg` — найденная часть кода;
- `ui/web-left.webp` и `ui/web-right.webp` — декоративные паутины, если они
  должны отличаться от нарисованных в CSS;
- `backgrounds/hero-overlay.webp` — дополнительная точечная/комиксная текстура
  поверх города, только если она у вас есть отдельным слоем.

Не загружайте скриншоты целого интерфейса вместо отдельных слоёв: текст,
кнопки, маршрут и шкала прогресса будут собраны в HTML/CSS, чтобы их можно было
редактировать.
